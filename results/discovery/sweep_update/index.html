mtgsweep CLI

One command sweeps about 6,200 independent US game-store sites in the cloud (R52 census, R53 GoDaddy, headless Shopify and 3 big online retailers, R55 +793 from Overture Maps), plus about 490 CrystalCommerce stores fetched from Roland's own computer, for an MTG sealed product, then merges, verifies and reports. It replaces the per-round r42, r43 and r44 scripts. The code and host lists are published with this page, so a new Cowork session pulls them to disk in one step.

Start a session

Ask Claude to load the toolkit. Claude reads this artifact's files to its workspace, no retyping:

Artifact read, this page's URL, paths = every file in the manifest below
cp -r <saved folder> /home/claude/mtgsweep
cd /home/claude/mtgsweep && python3 -m mtgsweep preflight && python3 tests/test_matchers.py

Preflight checks master counts, blocklist overlap and duplicates. Tests cover the Round 42-44 fixtures, bugs #41-#45, and the R49 deck fixtures (Savage Hunger, Commander Kits, Anthology reprints), and the R53 all-sealed fixtures (Secret Lair and Commander names, magic-trick shops, bug #53).

Run a sweep

# one named SKU from a JSON spec (Round 44 method)
nohup python3 -m mtgsweep run --profile single --spec specs/ltr-set-box.json --out runs/r46-ltr > runs/r46.log 2>&1 &

# every set/draft/play/beyond booster box 2020+ (Round 43 method)
nohup python3 -m mtgsweep run --profile boxes --out runs/r46-boxes > runs/r46b.log 2>&1 &

# named Commander and Brawl precons (Round 42 method; TCGCSV Market per deck from R49)
nohup python3 -m mtgsweep run --profile decks --out runs/r46-decks > runs/r46d.log 2>&1 &

# any MTG sealed product: boxes, packs, bundles, Commander decks, Secret Lair (R53)
nohup python3 -m mtgsweep run --profile sealed --out runs/r53-sealed > runs/r53s.log 2>&1 &

# matcher changed? re-classify without re-sweeping
python3 -m mtgsweep run --profile single --spec specs/ltr-set-box.json --out runs/r46-ltr --stages merge,verify,report

# new SKU: print a spec skeleton plus every sibling product to reject
python3 -m mtgsweep spec --group 23019 --product 484909

# test one title against a profile
python3 -m mtgsweep classify --profile boxes "Bloomburrow Play Booster" --variant "Box (36 Packs)" --price 130

Always run sweeps under nohup. A foreground shell call dies at 10 minutes. The log prints progress per route every 100 hosts.

CrystalCommerce leg (Roland's computer)

CC storefronts answer 410 to the cloud and drop plain OpenSSL handshakes even from a home IP. A Chrome TLS fingerprint works. Connect a folder, then in the local shell:

pip install --user curl_cffi
python3 cc_fetch.py cc_jobs.txt out 4 125      # one call = one 125 s chunk; rerun until remaining=0 (background jobs die between calls)
python3 cc_verify.py cc_verify.json ccv_out.jsonl 5 118   # pickup-only check on the rows verify picks

Stage the gzipped outputs, then in the cloud: tools/cc_import.py writes raw/crystalcommerce.jsonl, and tools/r51_finish.py applies pickup results, the abandoned-store filter and the report. Keep 4 to 5 workers; the script aborts after 25 hosts in a row on 410/403/5xx.

in_stock.csvTarget rows live in stock, ranked per group, each with a status label.
rollup.csvCheapest clean in-stock listing per SKU or deck, with stock depth and Market.
listings.csvEverything, all stock states.
coverage.mdPer-route status counts, drops, verification summary, and the headline table.

Where to change things

  • data/blocklist.txt for Roland's blocks. Remove the store from every master too. Preflight fails if a blocked host is still in a master.
  • data/pending_non_us.txt for the 9 USD-priced non-US stores awaiting a decision.
  • data/godaddy_ids.json for a GoDaddy store's account UUID when you add it to data/hosts/godaddy.txt (read it off any img1.wsimg.com/isteam/ip/<uuid>/ image path).
  • data/decks.json for the precon list. specs/*.json for single-SKU targets.
  • mtgsweep/profiles/boxes.py, SETS, for a new set. python3 -m mtgsweep sets-check lists TCGCSV sets with boxes that are missing.

After any change to code or data, republish this page with the changed files and save the same files to the project. Then the next session starts from the current version.
